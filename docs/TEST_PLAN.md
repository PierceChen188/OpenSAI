# OpenSAI 功能测试文档

> 本机部署下的功能测试。覆盖应用层、智联服务层（决策中枢）、服务定制网络层（设备端）、前端控制台、端到端场景、可观测性与健壮性、回归与稳定性。
> 部署：Redis + 中枢 server + 多个设备端实例 + Web 桥接，均运行于本机。

---

## 1. 文档说明
- **目的**：验证当前版本各组件功能正确、端到端可用、异常可控。
- **范围**：本机部署的全部功能组件。
- **读者**：研发、测试、评审。

## 2. 测试环境与准备
| 项 | 说明 |
|---|---|
| 操作系统 | Windows 10/11 |
| 运行时 | Python 3.13（虚拟环境 `.venv`）、Node（前端构建） |
| 中间件 | Redis（便携版，:6379） |
| 端口 | 中枢 :8888、Web 桥接 :5000、数据面 :9971+ |
| 部署 | 一键脚本：Redis + 中枢 + 若干设备端实例 + 桥接 |
| 测试数据 | CIFAR-10（协同感知）、合成数据块（ProduceBlob） |
| 工具 | 回归套件 `scripts/test_suite.py`、特性断言 `scripts/test_features.py`、综合功能套件 `scripts/test_full.py`、监控查看器、日志 |
| 被测版本 | 记录 git 版本号、前端构建哈希 |

## 3. 测试方法与用例模板
- **编号**：`<模块>-<序号>`；**优先级**：P0 核心 / P1 重要 / P2 增强。
- **用例字段**：编号 · 名称 · 优先级 · 目的 · 前置 · 步骤 · 预期 · 实际/判定。
- **通过准则**：预期全部满足、`errs=0`、关键字段/日志符合。
- **执行方式标注**：`[自动]`=由测试脚本断言；`[半自动]`=脚本+人工核对；`[人工]`=界面/视觉核对。
